# 手动添加链接功能说明

## 功能概述

新增了手动添加链接到TXT文件的功能，用户可以通过输入框直接输入拼多多客服链接，系统会自动验证链接格式并将其写入TXT文件中。

## 新增功能

### 1. 手动添加链接输入框
- 位置：在"文件导入导出"部分的TXT文件选择下方
- 功能：允许用户手动输入拼多多客服链接
- 验证：自动验证链接格式（必须包含pinduoduo.com或yangkeduo.com）

### 2. 添加按钮
- 功能：点击后将输入的链接添加到TXT文件中
- 快捷键：支持回车键快速添加
- 反馈：显示操作结果消息

### 3. 实时状态更新
- 导入状态：显示当前TXT文件状态
- 有效链接计数：统计正常链接数量
- 无效链接计数：统计异常链接数量

## 使用方法

### 基本操作
1. 在"🔗 手动添加链接"输入框中输入拼多多客服链接
2. 点击"➕ 添加"按钮或按回车键
3. 系统验证链接格式并添加到TXT文件
4. 输入框自动清空，状态显示实时更新

### 链接格式要求
- 必须包含 `pinduoduo.com` 或 `yangkeduo.com`
- 支持完整的URL格式
- 示例：
  ```
  https://mms.pinduoduo.com/janus/api/new?__oak_=xxx
  https://mms.yangkeduo.com/janus/api/new?__oak_=xxx
  ```

### 防重复机制
- 系统自动检查链接是否已存在
- 重复链接不会被重复添加
- 显示相应提示信息

## 技术实现

### 新增函数
1. **`addManualLink()`** - 手动添加链接的主要函数
2. **`updateTxtFileStatus()`** - 更新TXT文件状态显示
3. **事件监听器** - 按钮点击和回车键事件

### 存储机制
- 使用Chrome扩展的本地存储
- 链接以换行符分隔存储
- 支持异常链接标记（以`[异常]`开头）

### 状态管理
- 实时更新导入状态
- 动态计算有效/无效链接数量
- 自动重置状态显示

## 注意事项

1. **链接验证**：仅支持拼多多相关链接
2. **存储限制**：链接存储在Chrome扩展的本地存储中
3. **状态同步**：页面刷新后状态会自动恢复
4. **错误处理**：包含完整的错误处理和用户提示
